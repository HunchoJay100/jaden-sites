Infrastructure
How It All Works
Built on a Mac Mini running in the office. No cloud servers, no subscriptions beyond the AI.

Scheduling

Unix cron jobs trigger each agent on schedule. 6 scheduled tasks running 24/7 — morning brief, watchdog (4 runs), sentinel, crontab guard, and memory backup.

Delivery

All reports delivered via iMessage through a locked-down script that only texts Jaden's number. No email, no Slack — just a text on his phone.

Security

Every file locked to owner-only permissions. API keys loaded at runtime from encrypted env files. All JobTread access is read-only enforced — the system literally cannot modify job data.

Memory

Claude's memory is backed up nightly at 9pm with a restore script ready if anything goes wrong. Project context, preferences, and system knowledge persist across sessions.
