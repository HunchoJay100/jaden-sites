07 / Technical Discoveries

Anti-Bot Breakdown

Zillow (PerimeterX) Zillow

Beaten with persistent Chrome context. Full browser profile persists cookies and fingerprint across sessions, making requests indistinguishable from organic traffic.

Redfin (CloudFront) Redfin

Beaten with in-browser Stingray API. Executes search directly within the browser context using Redfin's internal API endpoints, bypassing CloudFront WAF entirely.

Realtor.com (Kasada) Realtor.com

NOT beaten. Kasada detects CDP (Chrome DevTools Protocol) at the connection level. Every Playwright/Puppeteer session is fingerprinted before the first request.

Homes.com (Akamai) Homes.com

Bypassed via agent dashboard login. Authenticated sessions through the agent portal avoid Akamai's bot detection entirely. Views, favorites, and leads all accessible.
