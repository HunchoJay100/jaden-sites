Health Scoring
Three Colors. Zero Guesswork.

Every job gets scored based on log freshness, budget status, and activity patterns.

[OK]

Green

Logged within 24 hours. Budget tracked. Crew is active. This job is running smooth — no action needed.

[!!]

Yellow

1–2 days since last log. Starting to drift. Keep an eye on it — might need a check-in call before it goes red.

[XX]

Red

2+ days dark or no budget set. This job needs attention right now. The Watchdog puts it at the top of your report.

Deep JobTread Access

The Watchdog speaks JobTread's native Pave query language — the same protocol their app uses internally. It pulls jobs, daily logs, cost groups, contacts, tasks, and more. Not a screen scrape. Not an export. A direct, authenticated API connection to your Flynn Developments account.

API Query
POST api.jobtread.com/pave
Authorization: Bearer ****

  $: { id: "Flynn Developments" },
