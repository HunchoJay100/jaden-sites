Context

The Problem

📂

Scattered Content

Google Drive folders with no brand context. Captions in random docs.

✗

No Brand Voice Control

Each brand has a different voice but no system enforces it. Easy to go off-brand.

📋

Manual Publishing

Copy-paste from docs to social platforms. No scheduling, no preview.

🤖

No AI Integration

Writing captions from scratch every time instead of using AI with brand voice guardrails.

💻

Single Machine Lock-in

All data lives in localStorage on one computer. Can't access from other machines.

📈

Zero Analytics Feedback

Content is created in a vacuum with no data on what's working. No connection to ad performance.

Design Direction

Dark editorial aesthetic inspired by Known.is and Riot.nyc. Bold Oswald typography, Libre Baskerville italic accents, Oxygen Mono for system text, #f6462b red-orange accent, massive whitespace, horizontal layouts, grain overlay. NOT Tron/neon/sci-fi.
