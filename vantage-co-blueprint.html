Typography

We build the operating system.

Inter throughout. Weight 500-600 display, tight letter-spacing -0.04em. Italic + weight bump = the signature move. Porto Rocha pattern.

Rejected

What we tried and killed.

Five color directions explored before locking pure mono. Each was built, reviewed, and rejected. The constraint is the feature.

Rolex Heritage

  • Gold accent, serif display type
  • Felt like a jeweler, not a consultancy

NVIDIA Edge

  • Electric green, gradient mesh backgrounds
  • Too tech-company, wrong audience signal

Linear Violet

  • Purple accent, dev-tool energy
  • Felt SaaS, not operator

Teal + Amber

  • Dual accent, warm-cool balance
  • Too busy, diluted the message

Amber Accent

  • Gold/amber as single accent
  • Close but felt like Flynn Dev, not Vantage

Pure Mono ✓

  • Zero color, italic emphasis only
  • "Color pops come from screenshots and such"
