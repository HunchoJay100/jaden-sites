What BidKit Does Today

5-Step Estimating Wizard

Walk through Project Info, Dimensions, Structural Trades, Finish Trades, and Summary. Each step builds on the last. No more hunting through Excel rows.

Live Calculations

Every number updates the instant you change an input. Running total bar always visible at the top. No "recalculate" button needed.

Build Type Presets

Select Garage, Barndo, Custom Home, or High-End and all default allowances, finish toggles, and builder fee percentages auto-set to match that build type.

35 Trade Cards

11 structural trades (footer, block, gravel, slab, framing, windows, doors, roofing, siding) and 24 finish trades. Each expandable with tier selection and editable inputs.

3 Export Formats

Excel multi-sheet workbook with full detail. Branded Proposal that opens in a new tab and prints to PDF. Bill of Materials with quantities for ordering.

Save & Reload Estimates

Save unlimited estimates in the browser. Switch between them from the dropdown. Auto-saves every 2 seconds so you never lose work. Import/export JSON backups.

Complex Floor Plans

L-shapes, bump-outs, irregular plans? Override fields let you enter the real heated SF and perimeter from your plans. L x W still works for simple builds.

Master Rate Database

Every rate is editable from the gear button. Change concrete price, labor rates, material costs. Persists between sessions. Reset to defaults anytime.

The Engine

How the Math Works

Every number in BidKit comes from a real formula — the same math we use on paper, just automated. Here's exactly how each trade calculates. Every rate shown can be changed on the fly from the gear panel or directly on the trade card.

Dimensions & Area Calcs

Total Under Roof Main (L x W) + Front Porch (L x W) + Rear Porch (L x W) + Garage (L x W) + Aux (L x W) + 2nd Story (L x W)
Perimeter 2 x (Length + Width) of main building — or use Override field for complex plans
Wall Area Perimeter x Wall Height
Roof Area Total Under Roof x Pitch Multiplier
Pitch multipliers: 4:12 = 1.054, 6:12 = 1.118, 8:12 = 1.202, 10:12 = 1.302, 12:12 = 1.414, 14:12 = 1.537

Footer

Cubic Yards Perimeter x Width(ft) x (Depth / 12) / 27 x 1.05 waste factor
Total (Yards x $200/yd) + Labor($650) + Stakes($150) + Pump Truck($750 if toggled)
Footer width default: 2ft. Depth default: 10". All rates adjustable.

Block Foundation

Block Count Perimeter / 1.333 x Number of Courses
Total Block Count x $7/block
1.333 = blocks per linear foot (16" block with mortar). Courses = rows of block height.

Gravel Fill

Volume Area x (Depth / 12) / 27 = Cubic Yards
Total Cubic Yards x 1.4 (yd-to-ton conversion) x $24/ton

Concrete Slab

Cubic Yards Slab Area x (Depth / 12) / 27 x 1.05 waste factor
Total (Yards x $192/yd) + (Area x $2/sf labor) + Steel & Plastic($500) + Termite($150)
Default slab depth: 4". Garage slabs often 6" for equipment loads.

Framing

Wall Material Total SF x Wall Rate($4-7/sf based on 2x4 or 2x6) x Complexity Multiplier(1.1-1.4)
Trusses Total Under Roof x $3.50/sf
OSB Sheathing (Roof Area + Wall Area) x $1.50/sf
Labor Total SF x $7/sf (editable directly on card)
Floor System Heated SF x $8/sf (only if crawlspace foundation)
Extras Posts($500) + Flashing($100) + Screws/Nails($400)
Complexity multiplier: 1.1 = simple rectangle, 1.2 = some bump-outs, 1.4 = complex design. All 6 framing rates are editable right on the card.

Roofing

Squares Roof Area / 100 = Roofing Squares
Shingles Squares x ($65 labor + $150 material) = Squares x $215
Screw-Down Metal Squares x ($180 labor + $160 material) = Squares x $340
Standing Seam Squares x ($300 labor + $375 material) = Squares x $675
Select roofing type on the trade card — rates swap automatically. Labor and material split visible.

Siding

Net Area (Perimeter x Wall Height + Gable Area) - Window/Door Openings
Vinyl/Lap Net Area / 100 x ($160 material + $180 labor)
5-Rib Metal Net Area / 100 x ($250 material + $250 labor)
Gable area auto-calculated from roof pitch and building width.

Windows & Doors

Windows Quantity x Unit Price x Color Multiplier x Pella Multiplier
Window Sizes 3x5: $385 | 3x6: $435 | 6x6: $970 | Transom: $235
Doors Front Entry: $800 | Rear Exit: $750 | Aux/Side: $750
Color multiplier: 1.0 (standard), 1.15 (colored), 1.6 (custom). Pella upgrade: 1.0, 1.1, or 1.8.

Dirtwork

Total Flat allowance: $3,000 (Standard) / $4,000 (Mid) / $5,500 (Complex)

Finish Trades — Formula-Based

Electrical (Heated SF + Garage SF + Bonus SF) x $8/sf + $2,500 hookup
Plumbing Fixture Count x $450/fixture (slab: $550/fixture)
Sheetrock Heated SF / 10 x $54/board
Paint Interior Heated SF x $4.25/sf
Paint Exterior Wall Area x $3.50/sf

Everything is Adjustable — On the Fly

Gear Panel

Bottom-left gear button opens the master rate database. Change any rate (concrete $/yd, labor $/sf, material costs) and every calculation updates instantly across the entire estimate. Rates persist between sessions via localStorage.

Trade Cards

Framing card has editable rate inputs right on the card (labor/sf, trusses/sf, OSB/sf, floor system/sf). Survey has quantity input. Toggle any line item on or off. Override any allowance directly.

Override Fields

Complex floor plan? Enter the real heated SF and perimeter from your plans. These override the L x W calculations. Leave them blank and L x W math takes over. Best of both worlds.

Builder Fee Slider

Drag from 20% to 35%. See the project total update in real time. Use 20% minimum for large simple jobs, 25% target for standard, 30% for small or complex builds.

Behind The Build

How This Came Together

The Problem

Every estimate started with an Excel spreadsheet. 81+ formulas across 20+ trade categories. Copy the template, manually enter dimensions, hunt for the right cells, hope you didn't break a formula. Every quote took hours. Comparing old estimates meant digging through folders. There was no way to quickly adjust rates across all estimates when material prices changed.

The Build Process

Jaden and Chief (Claude AI) built BidKit in a single session. Here's how it actually went down:

  • Started by reading every reference file: the master pricing database, the Bob Wetzel and Jeff Merrick quotes, the estimating structure doc, and the existing proposal templates
  • Hit the token output limit on the first attempt trying to write the whole file at once. Regrouped and broke it into 10-12 smaller chunks, writing and verifying each piece before moving on
  • Built the CSS design system first by pulling the exact styles from our existing branded proposals (the black and gold theme)
  • Wrote the pricing database as a JavaScript object translating every formula and rate from the Excel sheets
  • Built each step's UI one at a time, then wired up the calculation engine to make everything live
  • Discovered mid-build that the original pricing DB was built from only 2 estimates, not the full master database with 7 real jobs and A/B/C tier rates. That upgrade is the next priority
  • Fixed issues in real-time as Jaden tested: emojis looked corny (removed), running total blocked navigation (moved to sticky bar), logo had white box (removed), dropdown didn't match theme (restyled), new estimate wasn't fully clearing (fixed state management), dimensions needed L x W per area instead of just SF (restructured)
  • Every change was tested immediately by opening the file in the browser. No build process, no deployment needed. Just save and refresh

The Tech

BidKit is a single HTML file. No server, no database, no framework, no build process. Open it in any browser and it works. The entire app, including all styles and JavaScript, lives in one 2,100-line file. Estimates save to browser localStorage. Exports use SheetJS (a JavaScript library loaded from CDN) to generate real Excel files. The proposal export generates a complete branded HTML page in a new tab that you print to PDF.

What Makes This Different

  • Every formula is from OUR actual estimates, not generic construction software
  • The branded proposal output matches our existing Flynn Development proposals exactly
  • Rates are fully editable. When lumber prices change, update once and every future estimate reflects it
  • Build type presets mean a new estimate takes minutes, not hours
  • No subscription, no login, no internet required (except for fonts). We own it completely
  • Built specifically for how Flynn Development works, not a generic tool we have to adapt to

For The Team

What to Try & Watch For

01

Run a Real Estimate

Pick an upcoming job or a past quote you know the numbers on. Enter it into BidKit and see how close the output matches. Note where rates are off so we can calibrate.

02

Test the Exports

Generate an Excel sheet and a Proposal from the same estimate. Open the Excel in Google Sheets or Excel. Print the proposal to PDF. Are the numbers right? Does the format look professional?

03

Check the Rates

Click the gear icon (bottom-left) to open the master rate panel. Are these numbers current? Flag any that need updating. When we finalize rates, they become the new defaults for every estimate.

04

Break It

Try weird inputs. Leave fields blank. Enter a 10,000 SF home. Enter a 200 SF shed. Put in 14:12 pitch with standing seam. Find the edge cases where the math gets weird so we can fix them.

05

Missing Trades?

Is there a trade or line item you always include that's not here? A cost that gets forgotten? Write it down. We can add any trade card with whatever formula or allowance structure it needs.

06

Think About Workflow

How would this fit into your actual process? What would make it faster? Should the steps be in a different order? Would you want to skip straight to a specific trade? That feedback shapes the next version.
