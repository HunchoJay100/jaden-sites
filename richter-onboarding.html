01 // Installation

The full install chain.

Six installs. Copy and paste each command into your terminal. We'll walk through every one together, but here's the full picture.

1
Homebrew
The package manager for macOS. This is the foundation that installs everything else.
~2 minutes
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2
Ghostty Terminal
A fast, GPU-accelerated terminal built for exactly this kind of work. Way better than the default Terminal app.
~1 minute
$ brew install --cask ghostty
3
Node.js
JavaScript runtime. Required for Claude Code and most of the tools we'll be building.
~2 minutes
$ brew install node
4
Git + GitHub CLI
Version control and GitHub integration. You already know Git, so this will be fast. The CLI lets you manage repos, PRs, and issues from the terminal.
~3 minutes
$ brew install git gh
$ gh auth login
5
Claude Code
The autonomous coding agent. This is the whole reason we're here. One command and it's installed globally.
~1 minute
$ npm install -g @anthropic-ai/claude-code
6
Clone Your Onboarding Repo
We'll build a custom onboarding repository for Richter Technology on GitHub. It'll have your CLAUDE.md config, your memory files, starter scripts, and everything Claude Code needs to understand your operation from day one.
~1 minute
$ gh repo clone richter-onboarding
$ cd richter-onboarding && claude
