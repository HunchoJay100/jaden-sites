How It Works
From Install to Operations in Minutes

Paperclip runs locally on your machine. It's a Node.js server with a React dashboard. Ships with an embedded database so there's nothing to configure on first run.

01

Install

One command: npx paperclipai onboard --yes. That's it. The server starts, the dashboard opens, and you're looking at an empty company ready to build.

02

Hire Agents

Create roles and assign agents. Pick an adapter (Claude Code, OpenClaw, custom scripts, webhooks) and give each agent a name, role, and scope. Define who reports to who.

03

Assign Work

Create tickets with goals and instructions. Agents pick up work on their next heartbeat. Cross-team delegation flows automatically through the org chart.

04

Monitor Everything

One dashboard shows every agent's status, task progress, cost, and complete audit trail. Every decision traced. Every tool call logged. Total visibility.

Two Ways to Run It
Claude Code Subscription vs. API Tokens

Paperclip gives you two paths to power your agents. One costs nothing extra. The other unlocks the full potential of multi-model AI operations. Here's the difference and why it matters.

Starting Point

Claude Code Subscription

$0 extra

If you already pay for a Claude Code plan (Pro or Max), Paperclip has a built-in Claude Code adapter. Each agent you "hire" runs as a Claude Code session on your machine, using your existing subscription. No API key needed. No per-token billing. No surprise charges.

  • ✓ Runs on your existing subscription
  • ✓ No API keys to manage
  • ✓ Zero additional cost
  • ✓ Full Claude Code capabilities per agent
  • • Limited by subscription rate limits
  • • One model only (Claude)
  • • Agents share the same usage pool

This is how you start. Get Paperclip running, build your org chart, and prove the concept with 2-3 agents on staggered schedules. No financial risk.

Full Power

API Tokens

Pay per token

API tokens are keys you get directly from AI providers (Anthropic, OpenAI, Google, etc.) that let you call their models programmatically. Instead of chatting through an app, your code sends requests and gets responses. You pay per token (roughly per word) that goes in and comes out. This is how production AI systems work.

  • ✓ Mix models: Claude for reasoning, GPT for drafting, Gemini for analysis
  • ✓ No rate limits (scales with spend)
  • ✓ Agents run fully parallel, no shared pool
  • ✓ Access via OpenRouter: one key, dozens of models
  • ✓ Fine-grained cost tracking per agent, per task
  • ✓ Production-grade: the same way real companies deploy AI
  • ✓ Paperclip budget controls prevent runaway spending

This is where it gets serious. When you need 5+ agents running simultaneously, different models for different jobs, and zero bottlenecks, API tokens remove every constraint.

How API Tokens Actually Work
Think of It Like Hiring Contractors vs. Full-Time

Your Claude Code subscription is like a salaried employee. Fixed cost, always available, but you only get one person. API tokens are like hiring contractors. You pay by the hour, but you can hire as many as you need, from any firm, all working at the same time.

What's a Token?

A token is roughly one word (sometimes part of a word). When you send a prompt to an AI model via API, you pay for the tokens going in (your instructions) and the tokens coming out (the response). For example, Claude Sonnet costs about $3 per million input tokens and $15 per million output tokens. A typical agent task might use 5,000-20,000 tokens total, costing a few cents.

Where Do You Get Them?

You sign up at the provider's developer platform (console.anthropic.com for Claude, platform.openai.com for GPT, etc.), add a credit card, and generate an API key. That key goes into Paperclip's config. Or use OpenRouter, which gives you one API key that routes to 200+ models from every major provider.

Why Would You Pay Per Token?

Because it removes every bottleneck. Your subscription plan has rate limits: only so many requests per minute, only so many concurrent sessions. API tokens scale with your wallet. Need 10 agents running at the same time? Done. Need one agent on Claude and another on GPT-4 because it's better at a specific task? Done. This is how you go from "AI assistant" to "AI workforce."

The Unlock
Multi-Model Agent Teams Change Everything

When you're running agents via API, you're not locked to one model. You pick the best model for each job. That's the real power move.

Best for Reasoning

Claude Opus for Strategy

Your CEO agent that reviews goals, makes decisions, and delegates work. Claude Opus is the best reasoning model on the market. Give it the hard problems.

Best for Speed

Claude Haiku for Triage

Your ticket triage agent that needs to process 50 alerts fast. Haiku is cheap and quick. It doesn't need to be the smartest, it needs to be the fastest.

Best for Code

Claude Sonnet for Scripting

Your PowerShell factory agent that generates deployment scripts. Sonnet hits the sweet spot between capability and cost for code generation tasks.

Best for Content

GPT-4 for Client Emails

Some models write more naturally for certain formats. Assign your outreach agent to GPT-4 if it drafts better client-facing copy. Use the right tool for the job.
